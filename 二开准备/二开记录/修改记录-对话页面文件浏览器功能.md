# 修改记录 - 对话页面文件浏览器功能

> 日期：2026-04-27  
> 功能：在对话页面右侧添加文件浏览器面板，支持浏览、编辑、保存、删除 AI 工作目录下的文件

---

## 1. 需求概述

### 1.1 功能目标
在现有 Artifact 系统基础上扩展，增加：
- 浏览 AI 工作目录（`/mnt/user-data/workspace`）下的文件夹和文件
- 文件夹可展开/折叠，只显示 `.md/.txt/.json/.log` 格式的文件
- 点击文件可查看、编辑内容
- 支持保存和删除文件
- 复用现有的文件预览功能（ArtifactFileDetail）

### 1.2 技术方案
- **后端**：Python FastAPI 新增文件系统 API 路由
- **前端**：扩展现有 Artifact 组件，增加目录浏览和编辑功能
- **API 调用**：前端直接调用后端 FastAPI 接口

## 3. 后端实现

### 3.1 新增 API 路由

文件：`backend/app/gateway/routers/filesystem.py`

实现了 4 个 API 接口：

| 方法 | 路径 | 功能 |
|------|------|------|
| GET | `/api/threads/{thread_id}/filesystem/browse` | 浏览目录（支持扩展名过滤） |
| GET | `/api/threads/{thread_id}/filesystem/read` | 读取文件内容 |
| POST | `/api/threads/{thread_id}/filesystem/write` | 写入文件内容 |
| DELETE | `/api/threads/{thread_id}/filesystem/delete` | 删除文件 |

**关键特性：**
- 使用虚拟路径系统（`/mnt/user-data/workspace/...`）
- 自动路径验证，防止路径遍历攻击
- 文件大小限制（最大 10MB）
- 支持扩展名过滤（默认：md, txt, json, log）

### 3.2 路由注册

文件：`backend/app/gateway/app.py`

```python
from app.gateway.routers import (
    # ... 其他路由
    filesystem,
)

# 注册路由
app.include_router(filesystem.router)
```

## 5. 使用方式

### 5.1 打开文件浏览器
1. 在对话页面右上角找到 📄 文件图标按钮
2. 点击按钮打开右侧文件浏览器面板

### 5.2 浏览文件
1. 面板自动加载工作目录 `/mnt/user-data/workspace` 内容
2. 点击文件夹展开/折叠子目录
3. 点击文件打开查看/编辑面板

### 5.3 编辑文件
1. 点击文件旁边的 ️ 编辑按钮
2. 在编辑器中修改内容
3. 点击 💾 保存按钮保存修改
4. 点击 ✕ 取消按钮放弃修改

### 5.4 删除文件
1. 点击文件旁边的 🗑️ 删除按钮
2. 在确认对话框中点击 "Delete"
3. 文件被删除，面板关闭

## 6. API 接口文档

### 6.1 浏览目录

```
GET /api/threads/{thread_id}/filesystem/browse
```

**Query 参数：**
- `path` - 虚拟路径（默认：`/mnt/user-data/workspace`）
- `extensions` - 扩展名过滤（逗号分隔，默认：`md,txt,json,log`）

**响应：**
```json
{
  "currentPath": "/mnt/user-data/workspace",
  "parentPath": "/mnt/user-data",
  "entries": [
    { "name": "folder1", "path": "/mnt/user-data/workspace/folder1", "isDirectory": true },
    { "name": "file.md", "path": "/mnt/user-data/workspace/file.md", "isDirectory": false }
  ]
}
```

### 6.2 读取文件

```
GET /api/threads/{thread_id}/filesystem/read?path=/mnt/user-data/workspace/file.md
```

**响应：**
```json
{
  "path": "/mnt/user-data/workspace/file.md",
  "name": "file.md",
  "content": "文件内容",
  "size": 1024,
  "modifiedAt": "2026-04-27T10:00:00"
}
```

### 6.3 写入文件

```
POST /api/threads/{thread_id}/filesystem/write
Content-Type: application/json

{
  "path": "/mnt/user-data/workspace/file.md",
  "content": "新的文件内容"
}
```

**响应：**
```json
{
  "success": true,
  "path": "/mnt/user-data/workspace/file.md",
  "size": 512,
  "modifiedAt": "2026-04-27T10:00:00"
}
```

### 6.4 删除文件

```
DELETE /api/threads/{thread_id}/filesystem/delete?path=/mnt/user-data/workspace/file.md
```

**响应：**
```json
{
  "success": true,
  "path": "/mnt/user-data/workspace/file.md"
}
```

## 7. 技术细节

### 7.1 路径系统
- **虚拟路径**：`/mnt/user-data/workspace/...`
- **实际路径**：由 `resolve_thread_virtual_path()` 函数解析
- **安全机制**：自动防止路径遍历攻击

### 7.2 代理配置
- Next.js rewrite 规则：`/api/:path*` → `http://127.0.0.1:8001/api/:path*`
- 配置文件：`frontend/next.config.js`
- 后端端口：8001

### 7.3 文件类型过滤
- 默认支持：`.md`, `.txt`, `.json`, `.log`
- 可扩展：通过 `extensions` 参数自定义
