## 工作流一：organize（整理工作流）
文件 ： novel_organize.py

执行步骤：

1. confirm_chapter - 确认章节号、章组
2. create_task_folder - 创建 _task 目录
3. organize_world / organize_characters / organize_items / organize_storyline - 整理参考（可并行）
4. assemble_context - 汇总所有参考文件为 写作任务汇总.md

并行/串行配置：
- 由 `config.yaml` 中的 `subagents.workflow_parallel_enabled` 控制
- true：4个整理子 Agent 并行执行（适合线上模型）
- false：4个整理子 Agent 串行执行（适合本地模型）
注入的文件 ：

- 小说名片 card.json
- 当前状态卡 03-状态/当前状态卡.md
- 章节细纲 01-规划/chapters/{章组}-细纲.md
- 故事圣经 00-世界观/故事圣经.md
- 角色矩阵 00-世界观/角色矩阵.md
- 所有细纲文件
输出 ：

- 02-正文/{章组}/_task/世界观参考.md
- 02-正文/{章组}/_task/人物参考.md
- 02-正文/{章组}/_task/道具参考.md
- 02-正文/{章组}/_task/故事线参考.md
- 02-正文/{章组}/_task/写作任务汇总.md
## 工作流二：writing（写作工作流）
文件 ： novel_writing.py

执行步骤 ：

0. check_task_summary - 检查写作任务汇总文件是否已生成（未生成则终止工作流）
1. write_chapter - 调用 novel-writer 写正文
2. audit - 调用 continuity-auditor 审核
3. should_revise - 判断：通过 → 后处理，不通过 → 修改（最多2轮）
4. revise - 调用 novel-reviser 修改
5. post_process - 后处理（根据配置并行或串行）：
   - chapter-summarizer 生成章节摘要
   - state-settler 更新状态卡
   - hook-manager 更新伏笔池
   - card-manager 更新小说名片
6. sync_outline - 调用 outline-planner 同步细纲

并行/串行配置：
- 由 `config.yaml` 中的 `subagents.workflow_parallel_enabled` 控制
- true：后处理的4个子 Agent 并行执行（适合线上模型）
- false：后处理的4个子 Agent 串行执行（适合本地模型）

注入的文件 ：

- 写作任务汇总（传入的）
- 样式指纹 05-参考/样式指纹.md
- 上一章正文（可选）
- 章节正文（审核/修改/后处理时）
- 审计报告（修改时）
- 故事圣经、细纲、当前状态、伏笔池、摘要汇总、角色矩阵（审核时）
- 细纲、卷纲（同步时）
- 已有摘要汇总、状态卡、角色矩阵、支线板、情感弧线（后处理时）

输出 ：

- 02-正文/{章组}/第{N}章.md
- 04-审稿/第{N}章-审计报告.md
- 04-审稿/第{N}章-修改记录.md
- 03-状态/章节摘要汇总.md（追加）
- 03-状态/当前状态卡.md（更新）
- 03-状态/待办事项.md（更新）
- card.json（更新）

## 工作流三：post_process（后处理工作流）
文件 ： novel_post_process.py

说明：从 writing 工作流中独立出来的后处理流程，支持单章节/多章节批量处理，章节文件可自动查找。

执行步骤 ：

1. post_process - 对每个章节调用：
   - chapter-summarizer 生成章节摘要
   - state-settler 更新状态卡
   - hook-manager 更新伏笔池
   - card-manager 更新小说名片
2. sync_outline - 调用 outline-planner 同步细纲

并行/串行配置：
- 由 `config.yaml` 中的 `subagents.workflow_parallel_enabled` 控制
- true：4个子 Agent 并行执行（适合线上模型）
- false：4个子 Agent 串行执行（适合本地模型）

章节文件查找优先级：
1. 传入的 `chapter_content` 路径（如果提供了）
2. 根据 `chapter_group` 自动拼接路径：`02-正文/{章组}/第{N}章.md`
3. 在 `02-正文/` 目录下全局搜索 `第{N}章.md`

调用方式（单章节）：
```
调用 workflow 工具：
- workflow_name: "post_process"
- params: {"novel_name": "都市逍遥仙", "chapter_num": 6, "chapter_group": "06-10"}
- description: "对第6章进行后处理"
```

调用方式（多章节批量）：
```
调用 workflow 工具：
- workflow_name: "post_process"
- params: {"novel_name": "都市逍遥仙", "chapter_nums": [6, 7, 8], "chapter_group": "06-10"}
- description: "对第6-8章进行后处理"
```

注入的文件 ：

- 章节正文（自动查找或传入路径）
- 细纲、卷纲（同步时）

输出 ：

- 03-状态/章节摘要汇总.md
- 03-状态/当前状态卡.md
- 03-状态/待办事项.md
- card.json
