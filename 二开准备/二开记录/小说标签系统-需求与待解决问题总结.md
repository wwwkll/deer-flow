### 问题 1：前端选择器显示"没有找到小说"（🔴 高优先级）

**现象**：
- 后端 API 能正确返回 3 个标签路径
- 前端选择器仍然显示"没有找到小说"
- 浏览器 Network 显示部分请求失败

**已排查信息**：
```
后端日志显示：
2026-04-29 21:49:48 - [DEBUG] Found 1 book directories: [WindowsPath('C:/xiangmu/deer-flow/backend/.deer-flow/shared-data/novels/book')]

2026-04-29 21:49:48 - [DEBUG] Added TOC: /mnt/shared-data/novels/book/С˵C
```

**可能原因**：

3. **数据解析错误**：JSON 解析时可能遇到编码问题

**建议修复步骤**：
1. 确保后端返回的 JSON 使用 UTF-8 编码
2. 检查前端是否正确处理响应数据
3. 在浏览器控制台查看实际接收到的数据

**相关文件**：
- `backend/app/gateway/routers/novel_tags.py`

### 问题 2：Windows 控制台编码问题（ 中优先级）

**现象**：
- 后端日志中的中文路径显示为乱码
- 日志文件编码为 GBK，但 Python 使用 UTF-8

**根本原因**：
- Windows 控制台默认编码为 GBK
- Python 的 `pathlib.Path` 读取目录时正确处理中文
- 但日志输出到控制台时被 GBK 编码破坏

**已尝试的修复**：
```python
# novel_tags.py 开头添加了
if sys.platform == "win32":
    if sys.stdout.encoding != "utf-8":
        sys.stdout.reconfigure(encoding="utf-8")
        sys.stderr.reconfigure(encoding="utf-8")
```

**建议修复**：
1. 设置环境变量 `PYTHONUTF8=1`
2. 或使用 `chcp 65001` 设置控制台编码为 UTF-8
3. 或在 FastAPI 应用中配置日志编码

## 八、关键代码片段

### 8.1 后端扫描逻辑（novel_tags.py）
```python
def _scan_novel_tocs() -> list[str]:
    # 获取配置
    config = get_app_config()
    mounts = config.sandbox.mounts
    
    tocs = set()
    for mount in mounts:
        host_path = Path(mount.host_path)
        # 解析相对路径
        if not host_path.is_absolute():
            project_root = get_paths().base_dir.parent.parent
            host_path = (project_root / host_path).resolve()
        
        # 查找 book 目录
        book_dirs = _find_book_directories(host_path, max_depth=3)
        
        # 收集子目录
        for book_dir in book_dirs:
            for item in book_dir.iterdir():
                if item.is_dir():
                    relative = item.relative_to(host_path)
                    container_path = mount.container_path.rstrip("/") + "/" + str(relative).replace("\\", "/")
                    tocs.add(container_path)
    
    return sorted(list(tocs))
```

### 8.2 前端获取标签（hooks.ts）
```typescript
export function useNovelTags() {
  return useQuery<{ tags: string[] }>({
    queryKey: ["novel-tags"],
    queryFn: async () => {
      const response = await fetch("/api/novel-tags/");
      if (!response.ok) {
        throw new Error("Failed to fetch novel tags");
      }
      return response.json();
    },
    staleTime: 5 * 60 * 1000,
  });
}
```
