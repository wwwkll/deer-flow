# 工具与工具组配置指南

> 本文档记录 DeerFlow 项目中所有工具组（tool\_groups）和工具（tools）的定义、配置及使用规则。

## 一、配置架构

### 1.1 配置层级关系

```
config.yaml
  ├── tool_groups          # 定义工具组（按功能分类）
  │     └── name: web      # 工具组名称
  │
  └── tools                # 定义具体工具
        ├── name: web_search
        │     group: web    # 归属的工具组
        │     use: deerflow.community.ddg_search.tools:web_search_tool
        │     max_results: 5
        │
        └── name: read_file
              group: file:read
              use: deerflow.sandbox.tools:read_file_tool
```

### 1.2 核心概念

| 概念                  | 说明                           |
| ------------------- | ---------------------------- |
| **tool\_group**     | 工具组，用于组织工具，Agent 通过工具组获得一组工具 |
| **tool**            | 具体工具，必须指定所属的 `group`         |
| **tools 配置**        | Agent 配置中的工具白名单，必须是具体的工具名称   |
| **tool\_groups 配置** | Agent 配置中的工具组白名单，必须是工具组名称    |

## 六、配置规则

### 6.1 必须遵循的规则

1. **工具组必须先定义**
   - 所有工具使用的 `group` 必须先在 `tool_groups` 中声明
   - 例如：`group: file:write` 必须对应 `tool_groups` 中的 `name: file:write`
2. **Agent 配置中的工具过滤**
   - `tools` 列表：使用具体的**工具名称**（如 `read_file`、`write_file`）
   - `tool_groups` 列表：使用**工具组名称**（如 `file:read`、`web`）
   - 两者不能混用
3. **工具名称不能重复**
   - 同一配置文件中 `name` 必须唯一
   - 重复名称会导致工具注册失败
4. **use 路径格式**
   - 格式：`模块路径:工具实例名`
   - 示例：`deerflow.sandbox.tools:read_file_tool`
   - 示例：`my_tools.master_writer:master_writer`

### 6.2 常见配置错误

| 错误                                   | 说明                     | 正确写法                                                       |
| ------------------------------------ | ---------------------- | ---------------------------------------------------------- |
| `tools: [file:write]`                | 将工具组名放在 tools 列表       | 使用 `tool_groups: [file:write]`                             |
| `tool_groups: [read_file]`           | 将工具名放在 tool\_groups 列表 | 使用 `tools: [read_file]`                                    |
| `group: file:edit`                   | 使用了未定义的工具组             | 使用 `file:write` 或先在 tool\_groups 中定义                       |
| `tools: [writer_reader, file:write]` | 混用工具名和工具组名             | 拆分为 `tools: [writer_reader]` 和 `tool_groups: [file:write]` |

## 八、配置示例

### 8.1 标准 Agent 配置

```yaml
# 标准 Agent 配置 - 使用工具组
name: my-agent
description: 我的 Agent
tool_groups:
  - file:read
  - file:write
model: inherit
max_turns: 60
timeout_seconds: 1200
```

### 8.2 精细工具控制

```yaml
# 精细工具控制 - 使用具体工具名
name: restricted-agent
description: 受限 Agent
tools:
  - read_file
  - write_file
model: inherit
max_turns: 30
timeout_seconds: 600
```

### 8.3 子 Agent 配置

```yaml
# 子 Agent 配置 - 使用 tool_groups
subagent_enabled: true
subagents:
  custom_agents:
    my-subagent:
      description: 子 Agent 描述
      tool_groups:
        - file:read
        - file:write
      model: inherit
      max_turns: 40
      timeout_seconds: 900
```

## 九、开发新工具的规范

1. **定义工具实例**
   ```python
   # my_tools/my_tool.py
   from langchain.tools import BaseTool

   my_tool = BaseTool(
       name="my_tool",
       description="工具描述",
       ...
   )
   ```
2. **在 config.yaml 中注册**
   ```yaml
   tools:
     - name: my_tool
       group: file:write
       use: my_tools.my_tool:my_tool
       custom_param: value
   ```
3. **如果需要新工具组，先定义工具组**
   ```yaml
   tool_groups:
     - name: my:custom
   ```
4. **在 Agent 配置中使用**
   ```yaml
   tool_groups:
     - my:custom
   ```
