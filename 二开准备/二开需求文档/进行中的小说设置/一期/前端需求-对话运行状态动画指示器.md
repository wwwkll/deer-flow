# 需求文档 - 对话运行状态动画指示器

> 日期：2026-05-16
> 状态：待评审
> 关联：小说标签系统一期（对话列表分组展示）

---

## 一、需求背景

在多小说创作场景中，用户可能同时运行多个对话。当前左侧对话列表无法直观区分哪些对话正在运行、哪些空闲。需要：

1. **一眼识别**正在工作中的对话
2. **分组级别**也能感知该分组下是否有正在运行的对话
3. **低开销**的状态检测，避免频繁轮询

---

## 二、功能需求

### 2.1 动画图标

| 属性 | 说明 |
|------|------|
| 图标 | 铅笔（Pencil） |
| 运动方式 | **公转**（沿椭圆轨道运行），**非自转** |
| 轨道形状 | 椭圆（水平半径 > 垂直半径） |
| 动画周期 | 约 2~3 秒一圈 |
| 尺寸 | 图标约 14×14px，轨道区域约 20×12px |

### 2.2 显示位置

| 场景 | 显示规则 |
|------|----------|
| **对话项** | 对话正在运行 → 对话名称左侧显示动画 |
| **分组标题** | 分组下有运行中对话 → 分组名称左侧显示动画 |
| **空闲** | 不显示动画 |

### 2.3 状态检测

- **页面加载时**：检测一次所有对话，确定哪些在运行
- **有对话运行时**：每 10 秒检测一次
- **所有对话空闲时**：不检测（零开销）
- **用户发送新消息时**：立即启动检测

---

## 三、调研结论

### 3.1 现有机制分析

| 机制 | 位置 | 能力 | 局限 |
|------|------|------|------|
| `thread.isLoading` | `useStream` hook | 知道当前打开的对话是否在运行 | 仅单对话级别，不知道其他对话 |
| `client.runs.list(threadId)` | LangGraph SDK | 列出某个 thread 的所有 runs 及 status | 需逐个 threadId 查询，N 个对话要 N 次请求 |
| `RunManager.has_inflight(thread_id)` | 后端 | 判断某个 thread 是否有运行中的 run | 同样是单 thread 查询 |
| `RunManager.list_by_thread(thread_id)` | 后端 | 列出某个 thread 的所有 runs | 同上 |

**结论**：现有机制都无法批量查询"所有对话中哪些在运行"，需要新增一个轻量的后端接口。

### 3.2 方案选择

**方案A：前端逐个调用 `runs.list()`**
- 对 N 个对话发 N 次请求，不可接受

**方案B：新增后端批量接口**（✅ 采用）
- 在 `RunManager` 上新增一个 `list_running_thread_ids()` 方法
- 新增 `GET /api/threads/running-status` 端点
- 一次请求返回所有运行中的 thread_id 列表
- 极轻量：内存字典遍历，无 IO，响应 < 5ms

## 四、技术方案

### 4.1 后端：新增批量运行状态查询 API

**GET /api/threads/running-status**

```json
// 响应
{
  "running_thread_ids": ["thread-abc-123", "thread-def-456"]
}
```

**后端改动**：

1. `RunManager` 新增 `list_running_thread_ids()` 方法 — 遍历内存字典，筛选 pending/running 的 run，提取去重的 thread_id
2. `threads.py` 新增端点 — 调用上述方法返回结果

### 4.2 前端：全局运行状态检测

**新增文件**：`frontend/src/core/threads/use-running-threads.ts`

核心逻辑：
- 使用 `useQuery` + 动态 `refetchInterval`
- 查询结果非空 → `refetchInterval = 10000`（10秒轮询）
- 查询结果为空 → `refetchInterval = false`（停止轮询）
- 提供 `startPolling()` 方法供发送消息时触发

### 4.3 前端：铅笔公转动画组件

**新增文件**：`frontend/src/components/workspace/running-indicator.tsx`

CSS 动画实现公转：
```css
@keyframes pencil-orbit {
  0%   { transform: translate(0px, -6px); }
  25%  { transform: translate(8px, 0px); }
  50%  { transform: translate(0px, 6px); }
  75%  { transform: translate(-8px, 0px); }
  100% { transform: translate(0px, -6px); }
}
```

### 4.4 前端：集成到对话列表

**修改文件**：`recent-chat-list.tsx`

- 分组标题前：如果组内有运行中对话，显示 `RunningIndicator`
- 对话项前：如果该对话运行中，显示 `RunningIndicator`
