# 一期后端需求文档：小说标签系统

> 目标：为对话系统提供小说标签的 API 支持，包括标签枚举获取和标签数据存储

---

## 1. 需求概述

### 1.1 功能目标
- 提供 API 接口，扫描并返回所有可用的小说标签（从 workspace/book 目录）
- 利用现有的全局变量系统存储标签
- 支持在查询对话列表时返回小说标签信息

### 1.2 技术约束
- 复用现有的全局变量系统（已开发完成）
- 标签存储为对话级全局变量，`is_system=True`，`llm_editable=False`
- 保持与现有全局变量系统的完全兼容
- **不需要标签验证**：允许任意标签值
- **数据量不大**：当前不需要复杂的性能优化，简单缓存即可

---

## 2. 技术方案

### 2.1 标签数据来源

标签来源于配置的 `sandbox.mounts` 下的 `book`/`books` 目录：

```yaml
# config.example.yaml
sandbox:
  mounts:
    - host_path: "c:/xiangmu/deer-flow/backend/.deer-flow/shared-data"
      container_path: "/mnt/shared-data"
```

扫描规则：
1. 扫描所有配置的 host_path 目录
2. 在每个目录下查找名为 `book` 或 `books` 的目录（最多 3 级深度）
3. 收集这些 book/books 目录下的所有一级子文件夹名称
4. 返回容器路径格式（如 `/mnt/shared-data/novels/book/小说A`）

**重要说明**：
- 标签返回的是完整的**容器路径**，不是简单的文件夹名称
- 前端 UI 显示时会提取路径的最后一段作为小说名
- 这样做是为了后续可以知道小说的完整目录位置

### 2.2 数据存储方案

**利用现有的全局变量系统**（已开发完成，使用 SQLite 存储）：

存储位置：SQLite 数据库 `{DEER_FLOW_HOME}/global_variables.db`

调用方式（前端 onCreated 回调中）：
```
PUT /api/global-variables/threads/{thread_id}/novel_toc
{
  "value": "/mnt/shared-data/novels/book/小说A",
  "description": "当前正在进行的小说目录",
  "is_system": true,
  "llm_editable": false
}
```

**注意**：
- `novel_toc` 是对话级全局变量，存储的是完整路径
- 设置为系统变量（`is_system=True`），前端只读，不可编辑
- 大模型不可修改（`llm_editable=False`）
- 不选标签时不创建变量

## 3. API 设计

### 3.1 获取小说标签列表

**接口路径**：`GET /api/novel-tags/`

**请求参数**：无

**响应格式**：
```json
{
  "tags": ["/mnt/shared-data/novels/book/小说A", "/mnt/shared-data/novels/book/小说B", ...]
}
```

**注意**：返回的是完整容器路径，但前端 UI 显示时会提取最后一段作为小说名。

**实现逻辑**：
1. 从 `deerflow.config.app_config` 读取 `sandbox.mounts` 配置
2. 遍历每个 mount 的 host_path
3. 调用 `_find_book_directories()` 查找 `book`/`books` 目录（最多 3 级深度）
4. 对每个 book 目录，收集其直接子文件夹的**容器路径**
5. 返回排序后的路径列表
6. **使用 5 分钟简单缓存**，避免频繁扫描

**代码实现**：

```python
# backend/app/gateway/routers/novel_tags.py

from fastapi import APIRouter, HTTPException
from deerflow.config.paths import get_paths
import logging
import time

logger = logging.getLogger(__name__)
router = APIRouter()

# 简单缓存
_novel_tags_cache = {
    "tags": [],
    "last_updated": 0,
    "ttl": 300  # 5 分钟缓存
}

def _find_book_directories(base_path: Path, max_depth: int = 3) -> list[Path]:
    """查找 base_path 下名为 'book' 或 'books' 的目录"""
    book_dirs = []
    
    def search(current_path: Path, current_depth: int):
        if current_depth > max_depth:
            return
        try:
            if not current_path.is_dir():
                return
            for item in current_path.iterdir():
                if item.is_dir():
                    if item.name.lower() in ("book", "books"):
                        book_dirs.append(item)
                    else:
                        search(item, current_depth + 1)
        except (PermissionError, OSError):
            pass
    
    search(base_path, 0)
    return book_dirs

@router.get("/api/novel-tags/")
async def get_novel_tags() -> dict:
    """获取所有可用的小说目录路径（容器路径）"""
    current_time = time.time()
    
    # 检查缓存
    if (
        _novel_tags_cache["tags"]
        and current_time - _novel_tags_cache["last_updated"] < _novel_tags_cache["ttl"]
    ):
        return {"tags": _novel_tags_cache["tags"]}
    
    try:
        from deerflow.config.app_config import get_app_config
        config = get_app_config()
        mounts = config.sandbox.mounts if config and config.sandbox else []
        
        if not mounts:
            return {"tags": []}
        
        tocs = set()
        
        for mount in mounts:
            host_path = Path(mount.host_path)
            if not host_path.is_absolute():
                project_root = get_paths().base_dir.parent.parent
                host_path = (project_root / host_path).resolve()
            
            if not host_path.exists():
                continue
            
            book_dirs = _find_book_directories(host_path, max_depth=3)
            
            for book_dir in book_dirs:
                try:
                    for item in book_dir.iterdir():
                        if item.is_dir():
                            # 返回容器路径
                            relative = item.relative_to(host_path)
                            container_path = mount.container_path + "/" + str(relative)
                            tocs.add(container_path)
                except (PermissionError, OSError):
                    pass
        
        sorted_tocs = sorted(list(tocs))
        
        # 更新缓存
        _novel_tags_cache["tags"] = sorted_tocs
        _novel_tags_cache["last_updated"] = current_time
        
        return {"tags": sorted_tocs}
        
    except Exception as e:
        logger.error(f"Failed to scan novel tocs: {e}")
        raise HTTPException(status_code=500, detail=str(e))
```

## 4. 缓存设计

### 4.1 缓存策略

采用**简单 TTL 缓存**：

```python
_novel_tags_cache = {
    "tags": [],
    "last_updated": 0,
    "ttl": 300  # 5 分钟缓存
}
```

**优点**：
- 实现简单
- 适合当前数据量不大的场景
- 减少文件系统扫描频率

**缺点**：
- Agent 创建新小说目录后，最多需要等待 5 分钟才能在标签选择器中看到
- 无法实时反映文件系统变化

**后续优化方向**（如果需要）：
- 添加手动刷新缓存的 API
- 使用文件系统监听（如 `watchdog`）自动刷新

### 4.2 缓存失效场景

以下情况会导致缓存过期：
1. TTL 超时（5 分钟）
2. 服务重启（缓存在内存中）

## 5. 错误处理

### 5.1 异常场景

| 场景 | 处理方式 |
|------|---------|
| book 目录不存在 | 返回空标签列表 `{"tags": []}` |
| 权限问题 | 记录错误日志，返回空列表 |
| 目录结构异常 | 跳过异常目录，继续扫描 |
| 扫描超时 | 返回缓存数据（如果有） |

### 5.2 日志记录

