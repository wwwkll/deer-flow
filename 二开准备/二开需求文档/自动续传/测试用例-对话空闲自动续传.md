### 2.3 防卡死机制

| 用例编号 | 测试项 | 前置条件 | 测试步骤 | 预期结果 | 实际结果 | 状态 |
|---------|--------|---------|---------|---------|---------|------|
| FUN-18 | 快速停止检测 | 监控已启用，模拟 LLM 接口报错 | 连续3次续传后在2分钟内停止 | 检测到异常模式 | | |
| FUN-19 | 自动暂停 | 检测到快速停止模式 | 观察监控状态 | 监控自动暂停，显示 toast："LLM 接口持续报错，监控暂停，10分钟后重试" | | |
| FUN-20 | 10分钟后重试 | 监控已暂停 | 等待10分钟 | 自动恢复监控，尝试1次 | | |

| FUN-22 | 手动重启监控 | 监控已自动关闭 | 点击监控按钮重新启用 | 可以重新启用，计数器重置 | | |
| FUN-23 | 正常完成不触发防卡死 | Agent 正常完成任务 | 观察监控状态 | 正常停止，不触发防卡死机制 | | |
