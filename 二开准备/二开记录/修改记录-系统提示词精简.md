# 修改记录 - 系统提示词精简

## 日期
2026-05-09

## 修改文件
`backend/packages/harness/deerflow/agents/lead_agent/prompt.py`

## 修改内容
精简 `SYSTEM_PROMPT_TEMPLATE` 基础模板，去除写小说系统不需要的部分。

### 删除的内容
| 删除项 | 原文 | 节省字符数 |
|--------|------|-----------|
| **clarification_system** | 5种澄清类型+使用方法（~184 tokens） | ~739 chars |
| **citations** | 网络引用规范（~71 tokens） | ~287 chars |
| **working_directory 部分** | `/mnt/user-data/uploads` 和 `/mnt/user-data/outputs` 路径说明 | ~150 chars |

### 修改的内容
| 修改项 | 原文 | 修改后 |
|--------|------|--------|
| **role** | `an open-source super agent` | `a professional novel writing assistant` |
| **thinking_style** | `Break down: what's clear, ambiguous, missing? If unclear → ask clarification FIRST.` | `Outline your plan briefly, then provide the response.` |
| **response_style** | `Clear, concise, action-oriented. Use prose over bullet points by default.` | `Write in the same language as the user. For novel content, follow the style rules defined in SOUL.md.` |
| **critical_reminders** | `Clarify before acting; load skills before complex tasks` | `Follow SOUL.md instructions strictly` |
| **critical_reminders** | `Output to /mnt/user-data/outputs` | `Use same language as user; output novel files to the correct paths` |
| **working_directory** | 详细路径说明（含uploads、outputs、PDF转换等） | 简化为workspace说明 |

## 效果
| 指标 | 修改前 | 修改后 | 减少 |
|------|--------|--------|------|
| 模板字符数 | ~2167 | ~999 | **~54%** |
| 预估 token | ~541 | ~249 | **~292 tokens** |

## 影响范围
- **正向**：每次 LLM 调用节省约 292 tokens（基础模板部分）
- **风险**：如果未来需要使用 `ask_clarification` 工具，需重新添加澄清系统说明
- **说明**：该工具目前未在小说系统中使用，且各 SOUL.md 中已有独立的交互规范

## 注意事项
- 基础模板只是系统提示词的一小部分（~3-4%）
- 主要的 token 消耗来自各 agent 的 SOUL.md（占 70%+）
- 如需进一步精简，应重点关注 SOUL.md 的按需加载机制
